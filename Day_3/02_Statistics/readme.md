### Statistics in data Scince
- The science of collecting, analyzing, interpreting, and presenting data.
- foundational backbone that transforms raw data into reliable inshights, powers machine learning algorithm, and validates predictive models.

### Types of Statistics
- **Descriptive Statistics:** Summarizes and organizes the main features of a dataset using metrics like central tendency (mean, median, mode) and dispresion (variance, standard deviation, rarnge) to make large amounts of data undersatndable.
- **Inferential Statistics:**Uses a smaller sample of data to make predictions, test assumptions, or draw conclusions about a large population.

### Key Statistical Concept:
-**Probabilities and Distribution:**Models  uncertainity and predicts the likehood of fiture events.
-**Hypothesis Testing:**Evaluates assumptions or compare groups using tests like t-test, ANOVA, and chi-squared tests.
-**Correlation and Regression:**Measure relationships between variables and forcasts numerical outcomes.
--**Bayesian Statistics:**Incoperate prior domain knowledge to update the probability of the hypothesis as new data arrives.
